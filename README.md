# Book1 Data Insights

## Overview
This repository houses the data analysis pipeline, scripts, and visual reports derived from `Book1.xlsx`. It is designed to automate spreadsheet parsing, clean data anomalies, and generate key statistical metrics.

## Key Features
- **Automated Ingestion**: Reads and processes multi-sheet Excel workbooks using `pandas` and `openpyxl`.
- **Statistical Profiling**: Computes critical metrics including count, mean, median, min, max, and standard deviation.
- **Data Visualization**: Generates publication-ready charts and graphs to highlight trends and outliers.

## Repository Structure
- `Book1.xlsx`: Source dataset.
- `analysis.py`: Main execution script for data processing.
- `outputs/`: Saved visualizations and summary tables.
